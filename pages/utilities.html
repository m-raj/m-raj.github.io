PythonMatplotlibNeeds LaTeX

Publication-quality Matplotlib style

One rcParams update that makes every figure ready for a paper:

  • Serif text and math typeset by LaTeX, matching the paper body
  • Inward ticks on all four sides, with minor ticks
  • Thicker lines, smaller markers and a frameless legend
plot_style.py
{% highlight python %} import matplotlib.pyplot as plt params = { # Text: serif, typeset by LaTeX 'text.usetex': True, 'text.latex.preamble': r'\usepackage{amsmath}', 'font.family': 'serif', 'font.sans-serif': 'Times New Roman', 'font.size': 14, 'axes.formatter.use_mathtext': True, # Lines, markers and legend 'lines.linewidth': 2, 'lines.markersize': 4.0, 'legend.frameon': False, # x ticks: inward, top and bottom, with minor ticks 'xtick.direction': 'in', 'xtick.top': True, 'xtick.major.top': True, 'xtick.major.bottom': True, 'xtick.minor.visible': True, 'xtick.minor.top': True, 'xtick.minor.bottom': True, 'xtick.major.size': 6, 'xtick.major.width': 1, 'xtick.minor.size': 3, 'xtick.minor.width': 1, # y ticks: inward, left and right, with minor ticks 'ytick.direction': 'in', 'ytick.right': True, 'ytick.major.left': True, 'ytick.major.right': True, 'ytick.minor.visible': True, 'ytick.minor.left': True, 'ytick.minor.right': True, 'ytick.major.size': 6, 'ytick.major.width': 1, 'ytick.minor.size': 3, 'ytick.minor.width': 1, } plt.rcParams.update(params) {% endhighlight %}
How to use: run it once after importing Matplotlib, before making figures. It needs a LaTeX installation; without one, set 'text.usetex': False.
